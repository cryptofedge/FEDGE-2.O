# Melao's Studio

> *"Every idea deserves a beat. Every feeling deserves a song."*

A FEDGE 2.O skill that turns WhatsApp messages into real songs — actual MP3
audio, generated by Google Lyria and delivered as a WhatsApp track.

```
melao hazme una bachata sobre un amor a distancia
  → 🎼 "Mi Amor Lejano" — Bachata
  → [4.3 MB MP3]
  → lyrics
```

## Setup

Nothing to link. Lyria runs on the `GEMINI_API_KEY` already in FEDGE's `.env`.

1. Skill lives at `skills/melaos-studio/` (loaded automatically by `fedge-bot.js`)
2. Ensure `GEMINI_API_KEY` is set in `.env`
3. Optional: `GEMINI_MODEL` overrides the text model (default `gemini-pro-latest`)

## Usage

| Message | Result |
|---------|--------|
| any music idea | full ~3 min track |
| add "clip" or "corto" | ~30s version, faster |
| `melao status` | studio status |

Bilingual — Spanish requests produce Spanish songs.

## How it works

Gemini turns the raw message into a structured music prompt (genre, mood,
instruments, vocal style), then Lyria performs it. Full track generation takes
roughly 30–45 seconds; the skill sends a progress message meanwhile.

If Lyria is unavailable the skill degrades to a pre-filled `suno.com/create`
link rather than failing outright.

## Notes

- Lyria models are `-preview`; pricing is not yet verified. Check billing before
  putting this in front of users at volume.
- Pinned model IDs rot. `gemini-1.5-pro` was retired and failed silently on every
  message before this was caught — see `services/gemini.js`.
- The `LINK email password` flow from earlier versions is gone. Users should
  never be asked to send credentials over WhatsApp.
